# 法考应试策略与技巧

> 本文件总结法考客观题与主观题的高效应试方法，结合命题规律与阅卷实际。

## 一、客观题应试策略

### 1. 单选题（50题左右）
- **直接定位法**：概念清晰题直接选，不纠结。
- **排除法**：先排除明显错误项，再在剩余项中比较。
- **陷阱识别**：注意"应当/可以""一律/除外""必须/酌情"等限定词。

### 2. 多项选择题（约35题）
- 多选少选均不得分 → 没有十足把握不选"边际项"。
- 优先确认"绝对正确"的选项，再评估存疑项。
- 注意选项间的逻辑排斥（互斥项不可能同真）。

### 3. 不定项选择题（约15题，常附案例）
- 同一案例下 3–5 小问，前一问可能约束后一问推理。
- 先通读全案，再逐问作答，避免被局部信息误导。

### 4. 通用技巧
- **时间管理**：客观题每科 3 小时 / 100 题，单题平均 < 1.8 分钟；难题标记后跳。
- **卷一/卷二分日**：卷一（法治思想/理论法/刑法/刑诉/行政法）与卷二（民法/商经/民诉/三国法）分两套试卷，可分别侧重。
- **答题卡**：不定项务必核对题号，避免错位。

## 二、主观题应试策略

### 1. 答题结构（万能框架）
```
一、结论（开门见山，直接回答"是/否/构成XX"）
二、法律依据（写明具体法条或法理，如《民法典》第XX条）
三、案情分析（将事实要件与法律规范逐一对应）
四、结论重申（回答案问）
```

### 2. 案例分析题（刑法/民法/商法/行政法/民诉）
- **先定性后论证**：先给出法律定性（犯罪/违约/侵权/违法），再展开。
- **刑法**重点写：不法（构成要件符合性）→ 有责（责任能力/故意过失）→ 共犯 → 罪数 → 量刑。
- **民法**重点写：请求权基础（谁向谁，依据什么，主张什么）。
- **行政法**注意：复议 vs 诉讼的选择、程序合法性审查。

### 3. 法律文书题
- 严格遵循格式（首部/正文/尾部）：如起诉状、答辩状、代理词、判决书。
- 格式分占比高，务必写全当事人信息、诉讼请求、事实理由、法律依据。

### 4. 论述题（法治思想/法理）
- 采用"总—分—总"结构：提出观点 → 分点论证（理论+制度+案例）→ 总结升华。
- 熟练运用法治思想核心表述（如"十一个坚持"）。

### 5. 主观题时间管理
- 5 道题 / 4 小时，平均每题 40–45 分钟（含读题与构思）。
- 每题先列提纲（2–3 分钟）再动笔，避免逻辑混乱。
- 法条检索：熟悉官方《法律法规汇编》目录，定位不超过 3 分钟。

## 三、常见失分点
1. 客观题：审题漏看"不/错误的"等否定词。
2. 主观题：只有结论没有说理（"裸结论"不得分）。
3. 主观题：法条引用错误编号或张冠李戴。
4. 文书题：格式缺项、当事人列写错误。
5. 时间失控：某一题耗时过长，导致后面空白。

## 四、考前一周策略
- 停止大量新题，转为"错题本 + 考点卡"回顾。
- 主观题每日手写 1 套保持手感。
- 打印并熟悉法条汇编索引。
- 调整作息，保证考试日状态。

## 五、诚信提醒
- 客观题/主观题均为国家统一考试，严禁泄题、作弊。
- 本 Skill 提供的模拟题仅供练习，与真题无直接关联。
