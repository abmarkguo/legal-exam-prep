# 主观题解题指南 · Subjective Question Guide

> 主观题 = 案例分析 / 法律文书 / 论述，1卷180分，4小时，机考，跨题型**不可回退**。

## 1. 三类题型

| 题型 | 核心能力 | 答题结构 |
|------|----------|----------|
| 案例分析 | 法律适用与推理 | IRAC：争议焦点→法律适用→结论 |
| 法律文书 | 格式与规范 | 标题/当事人/请求/事实/理由/结论 |
| 论述 | 法治思想与法理 | 观点→论据（法条+理论）→总结 |

## 2. IRAC 答题法（案例分析通用）

- **Issue（争议焦点）**：先识别案件的法律关系与争议点。
- **Rule（法律规范）**：援引具体法条/司法解释（写清条号或内容）。
- **Application（适用）**：将事实套入规范，逐步推理。
- **Conclusion（结论）**：给出明确判断。

> 主观题采分看"说理过程"，不只看结论。法条写不准时，写清规范内容亦可得分。

## 3. 法律文书要点

- 常见：起诉状、答辩状、代理词、法律意见书等。
- 结构：标题、当事人信息、诉讼请求/答辩意见、事实与理由、法律依据、落款。
- 重格式规范与逻辑完整，不要求穷尽所有细节，但要素不能缺。

## 4. 论述题要点

- 常以习近平法治思想、法理学为素材。
- 结构：开宗明义（观点）→ 分层论证（结合法治实践/法条/理论）→ 升华总结。
- 忌空泛，须有"法言法语"与具体制度支撑。

## 5. 机考与时间

- 4小时、跨题型不可回退，须合理分配：先易后难，案例分析留足时间。
- 熟练输入法（搜狗/QQ全拼、五笔），提前适应。
