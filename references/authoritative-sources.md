# 法考权威来源与溯源规范

> 法考内容必须准确、可溯源，不能有误导性信息。本文件规定本 Skill 输出内容的权威依据层级与引用规范。

## 一、权威来源层级（优先级从高到低）

| 层级 | 来源类别 | 具体文献 | 用途 |
|------|----------|----------|------|
| L1 | 法律（全国人大及其常委会制定） | 《民法典》《刑法》《刑事诉讼法》《民事诉讼法》《公司法》（2024修订）等 | 考点与答案的终极依据 |
| L2 | 司法解释与立法解释 | 最高人民法院/最高人民检察院司法解释、全国人大常委会解释 | 细化裁判规则、高频命题点 |
| L3 | 行政法规与部门规章 | 国务院条例、部委规章 | 行政法、经济法相关考点 |
| L4 | 官方考试大纲与教材 | 司法部《国家统一法律职业资格考试大纲》；法律出版社《辅导用书（九大本）》《客观题指导用书》《案例分析指导用书》 | 命题范围与重点界定 |
| L5 | 指导性案例与典型案例 | 最高人民法院指导性案例、公报案例、典型案例 | 主观题案例素材、裁判要旨 |
| L6 | 学术通说与权威教材 | 主流法考培训机构讲义（仅作辅助理解，不可作为唯一依据） | 解释疑难、补充视角 |

## 二、引用格式规范

输出任何考点、解析、答案时，**必须**标注来源，格式如下：

```
【考点】正当防卫的成立条件
【依据】L1《刑法》第20条；L2《关于依法适用正当防卫制度的指导意见》（法发〔2020〕31号）
【要点】防卫起因（不法侵害现实存在）、防卫时间（不法侵害正在进行）、防卫意图、
        防卫对象（不法侵害人）、防卫限度（明显超过必要限度造成重大损害=防卫过当）
```

## 三、时效与版本管理

1. **新法优于旧法、特别法优于一般法**：当法律修订（如2024年《公司法》《刑法修正案（十二）》《行政复议法》），一律以最新生效版本为准。
2. **标注生效时间**：涉及修订法律的考点，须注明"本法自YYYY年MM月DD日起施行"。
3. **冲突处理**：若不同层级来源冲突，按 L1 > L2 > L3 > L4 顺序优先；L5/L6 仅用于说明，不推翻 L1–L4。

## 四、真题与模拟题的诚信边界

1. **2018年（含）以后司法部不再公布真题与标准答案**：2018年后仅有考生"回忆版"，内容不完整且非官方。
2. **标注来源性质**：
   - 2018年前真题 → 标注 `【真题 · 年份】`
   - 回忆版 → 标注 `【回忆版 · 年份 · 未经官方确认】`
   - 本 Skill 命制 → 标注 `【模拟题 · 非真题】`
3. **禁止冒充**：模拟题与回忆版**绝不**伪称官方真题或标准答案。
4. **答案提示**：对于法律存在争议或新法修订导致的答案变化，须注明"原答案为X，新法下应为Y"。

## 五、溯源自检清单（每条输出前核对）
- [ ] 是否标注了 L1–L4 级别的法条/司法解释依据？
- [ ] 引用的法律是否为最新生效版本？
- [ ] 真题/回忆版/模拟题是否明确标注了来源性质？
- [ ] 主观题案例是否可对应到 L5 指导性案例或实务裁判规则？
- [ ] 无法核实的内容是否标注 `【待核实】`？

> 任何标注 `【待核实】` 的内容，应在回复中明确提示用户以官方最新文件为准。
