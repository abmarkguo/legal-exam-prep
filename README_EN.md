# Legal Exam Prep Skill

> An OpenClaw Skill that helps law-school students pass the **National Unified Legal Professional Qualification Examination (China Bar Exam / 法考)**.
> Built around **lookup + practice**, with **authoritative, traceable** content. Covers both the objective and subjective stages across all 18 subjects.

[中文 README →](./README.md)

---

## Why this Skill

The China Bar Exam is notoriously difficult. Key challenges:

- **Two-stage exam**: Objective test (300 pts, valid for 2 years) → Subjective test (180 pts: case analysis / legal document / essay).
- **18 subjects**: Volume 1 (Xi Jinping Thought on Rule of Law / Jurisprudence / Constitutional Law / Chinese Legal History / Public International Law / Judicial System / Criminal Law / Criminal Procedure / Administrative Law) + Volume 2 (Civil Law / IP / Commercial Law / Economic Law / Environment Law / Labor Law / Private International Law / International Economic Law / Civil Procedure).
- **No official questions after 2018**: The Ministry of Justice stopped publishing real questions and model answers; only "recall versions" (unofficial) exist. Practice resources are scarce.
- **High authority bar**: Laws change yearly (e.g., 2024 new Company Law, Amendment XII to Criminal Law, revised Administrative Reconsideration Law). Content must be accurate and traceable.

This Skill centers on **lookup + practice**, helping candidates study systematically, drill precisely, and trace every source — even without official past papers.

---

## Four Core Modules

| Module | Function | Description |
|--------|----------|-------------|
| **1. Knowledge Lookup** | 考点速查 | Search by subject / topic / statute; linked to statutes, judicial interpretations, official textbooks |
| **2. Objective Practice** | 客观题专项练习 | Single / multiple / indefinite-choice drills with analysis, point mapping, error notes |
| **3. Subjective Training** | 主观题案例分析训练 | Case analysis / legal document / essay method training with worked exemplars |
| **4. Mock Generation** | 趋势驱动模拟题 | Syllabus + new-statute + trend-driven high-quality mock questions to fill the practice gap |

## Authoritativeness

Every output cites its source, following a layered traceability standard (see `references/authoritative-sources.md`):

| Level | Source |
|-------|--------|
| L1 | Statutes (NPC & its Standing Committee, e.g. Civil Code, Criminal Law) |
| L2 | Judicial & legislative interpretations |
| L3 | Administrative regulations & departmental rules |
| L4 | MOJ Exam Syllabus + Law Press textbooks (9-volume set) |
| L5 | SPC guiding cases &公报 cases |
| L6 | Scholarly consensus (auxiliary only) |

> **Currency first**: New law supersedes old. Revised statutes are always cited at their latest effective version.

### Integrity boundary
- Since 2018 the Ministry of Justice no longer publishes real questions or model answers; only unofficial "recall versions" exist.
- Questions generated by this Skill are **explicitly labeled `【Mock · Not Real】`** and **never presented as official**.
- Anything unverifiable is marked `【To Verify】` with a pointer to the latest official source.
