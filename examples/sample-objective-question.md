# 示例：客观题（单选 + 多选）

> 本示例展示基于本 Skill 生成的法考客观题质量与解析规范。

## 示例一：单选题（刑法）

**【题源】** 【模拟题 · 非真题】
**【科目】** 刑法
**【难度】** 中等
**【考点】** 正当防卫

**【题干】**
甲遭乙持刀抢劫，反抗中将乙打成重伤。关于甲的行为，下列哪一说法正确？
A. 甲成立防卫过当，应负刑事责任
B. 甲成立正当防卫，不负刑事责任
C. 甲成立故意伤害，因造成重伤结果
D. 甲成立避险过当

**【答案】** B

**【解析】**
根据《刑法》第20条第3款（L1），对正在进行的行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪，采取防卫行为造成不法侵害人伤亡的，不属于防卫过当，不负刑事责任（特殊防卫/无限防卫）。乙持刀抢劫属严重危及人身安全的暴力犯罪，甲反抗致乙重伤属特殊防卫，成立正当防卫。
- A 错：特殊防卫无过当之忧。
- C 错：正当防卫排除犯罪性。
- D 错：本案为防卫非避险。

**【易错点】** 混淆一般防卫限度与特殊防卫；误以为重伤结果即过当。
**【依据】** L1《刑法》第20条；L2《关于依法适用正当防卫制度的指导意见》（法发〔2020〕31号）

## 示例二：多项选择题（民法）

**【题源】** 【模拟题 · 非真题】
**【科目】** 民法
**【难度】** 较难
**【考点】** 违约责任与合同解除

**【题干】**
甲向乙购买设备，约定2025年3月1日交货。乙迟至5月仍不交货且明确表示不再履行。下列哪些说法正确？
A. 甲可解除合同
B. 甲解除合同的，可请求乙承担违约责任
C. 甲只能请求继续履行，不得解除合同
D. 甲可请求赔偿包括可得利益在内的损失

**【答案】** A、B、D

**【解析】**
- A 对：乙迟延履行且明确表示不履行（根本违约），甲可依《民法典》第563条解除合同。
- B 对：合同解除不影响甲请求违约责任（《民法典》第566条第2款）。
- C 错：根本违约下甲有权选择解除而非只能继续履行。
- D 对：违约赔偿包括合同履行后可获得的利益（《民法典》第584条），但不得超过违约方订立合同时预见到或应当预见到的损失。

**【依据】** L1《民法典》第563条、第566条、第584条
**【答题技巧】** 先确认绝对正确项（A、B），再评估存疑（D属可得利益，亦正确）；互斥项（C）排除。
