# Legal Exam Prep · 法考备考工具箱

> 面向**法学院学生**的**国家统一法律职业资格考试（法考）**一站式「可查可练」备考工具箱。
> 覆盖客观题 + 主观题两阶段，权威、可追溯、能练能讲。

---

## 1. When to use this skill

Activate when a law student (or anyone preparing for 法考) asks to:

- **Look up** a 法考考点 by 科目 / 学科 / 考点，并看到对应法条、司法解释、官方教材依据
- **Practice** objective questions (单选 / 多选 / 不定项) with explanations
- **Train** subjective case-analysis / legal-document / essay answering
- **Get mock questions** that mirror the post-2018 proposition trend (real questions no longer published)
- **Plan** a study path from objective → subjective

If the request is from a **faculty** member wanting to analyze/teach questions, route to the
companion teacher-facing skill.

---

## 2. The 法考 system in one screen

| Stage | Papers | Questions | Points | Pass | Validity |
|-------|--------|-----------|--------|------|----------|
| 客观题 | 卷一 + 卷二 | 100 each (50 single×1 + 50 multi/indeterminate×2) | 300 | 180 (≈60%) | current year + next year |
| 主观题 | 1 paper | case analysis / legal document / essay (+ optional choice) | 180 | 108 (60%) | — (4h, computer-based) |

- **Order**: pass 客观题 first, then sit 主观题 (same year or next year).
- **Computer-based** (机考), batched over two days (Sept); 主观题 in Oct.
- **Critical constraint**: since **2018**, MOJ no longer publishes real questions/answers.
  Post-2018 "真题" are candidate **recall versions (回忆版)** — simplified.
  → Practice must combine: **pre-2018 real questions** + recall versions + **high-quality mock questions**.

### 18 subjects (across the two objective papers)

- **Paper I**: 习近平法治思想 · 法理学 · 宪法 · 中国法律史 · 国际法 · 司法制度和法律职业道德 · 刑法 · 刑事诉讼法 · 行政法与行政诉讼法
- **Paper II**: 民法 · 知识产权法 · 商法 · 经济法 · 环境资源法 · 劳动与社会保障法 · 国际私法 · 国际经济法 · 民事诉讼法（含仲裁制度）
- **Subjective**: 习近平法治思想 · 法理学 · 宪法 · 刑法 · 刑诉 · 民法 · 商法 · 民诉 · 行政法 · 司法制度和法律职业道德 (选作题)

## 3. Four core modules

### Module A — Point Lookup (考点速查)
Retrieve any 法考考点 by 科目 / 学科 / 关键词, with traceable authority.

- Map the point to: exam syllabus clause → statute article → judicial interpretation → official textbook (九大本) chapter.
- Mark **new / revised (新增新修)** points each year — these are frequent proposition hot-spots.
- Output: a point card. See `templates/point-query-template.md`.

### Module B — Objective Question Drill (客观题专项练习)
Generate / organize objective questions across 单选 / 多选 / 不定项.

- Each question: stem + options + answer + **解析** + **考点映射** + **易错分析** + **法条依据**.
- Tag by 科目 / 难度 / 认知层次 (记忆 / 理解 / 应用).
- Output: `templates/objective-single-choice-template.md`, `objective-multiple-choice-template.md`.

### Module C — Subjective Case-Analysis Training (主观题案例分析训练)
Train the answering logic for 案例分析 / 法律文书 / 论述.

- Case analysis: 法律关系识别 → 争议焦点 → 法律适用 → 结论 (IRAC-style).
- Legal document: 结构模板 + 格式要点.
- Essay (论述): 法治思想 / 法理 论述框架.
- Output: `templates/subjective-case-analysis-template.md`, `subjective-essay-template.md`,
  `subjective-legal-document-template.md`.

### Module D — Trend-Driven Mock Questions (趋势驱动模拟题)
Because real post-2018 questions are unavailable, generate **high-quality mock questions**
that mirror the current proposition trend: cross-chapter / cross-subject integration,
flexible angles, new-statute emphasis.

- Clearly labeled `【模拟题 · 非真题】`.
- Driven by: syllabus + new/revised points + official 指导用书 example style + recall-version patterns.
- Feeds Modules A→B→C to close the practice gap.

## 4. Authoritative grounding (always cite)

In priority order, every output must be traceable:

1. **MOJ official syllabus** — 《国家统一法律职业资格考试大纲》(司法部制定，每年5月发布)
2. **Law Press official textbooks** — 《辅导用书（九大本）》《客观题指导用书》《案例分析指导用书》
3. **Current statutes** — 宪法 / 民法典 / 刑法 / 刑诉法 / 行政法 / 民诉法 / 商经法等（全国人大）
4. **Judicial interpretations** — 最高人民法院 / 最高人民检察院 司法解释
5. **Guiding cases** — 最高人民法院 指导性案例
6. **Recall-version real questions** — labeled with year & source; pre-2018 ones are "real"

When a claim cannot be sourced, mark `【待核实】`. Never present mock questions as official.

## 5. Standard workflow (look-up → practice → assess)

```
Candidate input (subject / point / practice need)
        │
        ▼
[A] Point Lookup      ──► point card (syllabus → statute → interpretation → textbook)
        │
        ▼
[B] Objective Drill    ──► single/multiple/indeterminate with analysis
        │
        ▼
[C] Subjective Training──► case-analysis / document / essay with IRAC logic
        │
        ▼
[D] Mock Questions     ──► trend-driven fills post-2018 gap
        │
        ▼
[Assess] wrong-point review ──► refine lookup & practice (loop)
```

## 7. Operating rules

- **Traceability first.** Every point and question cites statute / interpretation / textbook.
- **Honest about sources.** Mark `【模拟题 · 非真题】` for generated questions; `【回忆版】` for recall; `【待核实】` for unsourced.
- **Stage-aware.** Objective = speed + accuracy under computer-based timing; subjective = IRAC reasoning + writing.
- **New/revised emphasis.** Each year's 新增新修 are proposition hot-spots — flag them.
- **Reusable output.** Always deliver in a template format the candidate can store and reuse.
