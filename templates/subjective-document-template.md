# 主观题 · 法律文书题模板

> 适用：法考主观题法律文书写作（起诉状 / 答辩状 / 代理词 / 判决书等）
> 格式分占比高，务必写全首部、正文、尾部。

---

**【文书类型】** 民事起诉状
**【来源】** 【模拟题 · 非真题】

## 格式框架

```
民 事 起 诉 状

原告：张三，男，1985年X月X日生，汉族，住址……，联系方式……
被告：李四，男，……（自然人信息）
       或：XX公司，住所地……，法定代表人……

诉讼请求：
1. 判令被告支付货款人民币XX元及逾期利息；
2. 本案诉讼费由被告承担。

事实与理由：
  （按时间顺序叙述法律事实，指出被告违约/侵权，引用法条）
  原告与被告于X年X月X日签订《XX合同》……被告未按约履行……
  依据《民法典》第XX条，被告应承担……责任。

此致
XX人民法院

具状人（签名）：张三
X年X月X日

附：1. 本状副本X份
    2. 证据材料X份
```

## 写作要点
1. **首部**：法院名称、文书名称、当事人身份信息（自然人/法人列写规范）。
2. **诉讼请求**：具体、明确、可执行（金额+利息+费用承担）。
3. **事实与理由**：事实清楚、逻辑连贯；理由部分写明法律依据与推理。
4. **尾部**：致送法院、具状人、日期、附项。
5. **常见失分**：当事人信息缺项、诉讼请求模糊、未引用法条、格式错乱。

**【评分侧重】** 格式完整性（约40%）+ 内容准确性（约60%）。
